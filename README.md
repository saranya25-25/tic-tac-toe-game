*Tic Tac Toe Game*

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

Features:
 Two-player gameplay
 Win detection logic
 Reset game button
 Responsive UI
 Interactive game board
 Winning line highlight
 
Technologies Used:
 HTML
 CSS
 JavaScript
 
Concepts Learned:
 DOM Manipulation
 Event Listeners
 Arrays
 Game Logic
 Conditional Statements
 Functions
 Responsive Design
